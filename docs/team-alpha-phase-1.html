الوحدات الست — Six Core Modules

شرح هندسي — ما الذي يحله كل جزء وكيف يتصل بالباقي
1

Tourist Profile Schema

المستخدم يعبّي الفورم: الجنسية، عدد الأشخاص، المدة، الاهتمامات، الميزانية. نعمل Model واحد — TouristProfile — يجمع هالحقول + validation قبل ما يدخل الـ Agent.

{
  "nationality": "German",
  "people": 4,
  "duration": 1,
  "interests": ["archaeology"],
  "budget": 300
}
TouristProfile JSON │ ▼ Schema + Validation │ ▼ Tourism Agent
  • people لا يكون 0
  • budget لا يكون سالب
  • duration لازم أكبر من 0

الـ Agent ما لازم يتعامل مع بيانات غلط — نرفضها قبل ما توصله.

No AI No LLM Schema + Validation
2

Generate Package API

React ما تتكلم مع الـ Agent مباشرة. POST /api/v1/packages/generate يستقبل الـ JSON ويمرّره عبر Agent Service — مش للـ Agent مباشرة.

React │ │ POST /api/v1/packages/generate ▼ FastAPI Endpoint │ ▼ Agent Service ← Auth · Logging · Monitoring (لاحقاً) │ ▼ Tourism Agent

Phase 1 — implementation بسيطة وكافية:

@app.post("/api/v1/packages/generate")
def generate(profile: TouristProfile):
    result = agent.run(profile)
    return result
ما بيفكّر يستقبل ويمرّر Agent Service layer
3

Tourism Agent

الـ Agent orchestrates the generation workflow — ما بيكتب الـ prompt بنفسه. هو ينادي المكوّنات ويفصل المسؤوليات.

Tourism Agent │ ├── calls Prompt Builder ├── calls LLM Manager └── validates Output │ ▼ Tourism Package JSON
Orchestrator Separation of concerns
4

Prompt Builder

يحوّل المدخلات لـ تعليمات واضحة للـ LLM. مصمّم يكون قابل للتوسع — مش مربوط بالبروفايل فقط.

الآن — Phase 1

  • Tourist Profile
  • Package rules
  • JSON output format

لاحقاً — Phase 2+

  • Retrieved Knowledge (RAG)
  • Weather Context
  • SME Information
  • Decision Rules

LLM Manager

طبقة بين الـ Agent والموديل — Claude اليوم، GPT أو Gemini لاحقاً. مسؤول عن:

  • API connection
  • Model configuration
  • Temperature · Tokens
  • Error handling · Retry
Agent │ │ llm.generate(prompt) ▼ LLM Manager │ ├── Claude API ├── GPT API └── Retry handling
Abstraction layer Swappable providers
6

Output Schema + Validation

الـ LLM أحياناً يرجّع JSON قريب لكن فيه مشكلة. المسار الصحيح:

LLM Response │ ▼ JSON Parser │ ▼ Package Schema Validation │ ┌────┴────┐ ▼ ▼ Valid Invalid │ │ ▼ ▼ Return Retry / Fix
{
  "title": "Amman Heritage Tour",
  "itinerary": [
    { "day": 1, "place": "Roman Theatre" }
  ],
  "budget": 250,
  "explanation": "Chosen for archaeological interest"
}
Parser → Validate Retry on invalid
