🏗️ Backend Architecture

  • FastAPI — طبقة API نظيفة بدون business logic
  • Package Service — orchestration بين validation والـ agent
  • Package Builder Agent — بناء prompt، استدعاء LLM، parse، retry

  • Business rules: budget · travelers count · children ages
  • JSON parser + response validator + retry on invalid LLM output
